# Кабінет учителя — етап 1

Локальний планувальник домашніх завдань українською мовою.

## Що вже працює
- створення, редагування, пошук, дублювання та видалення завдань;
- вибір предмета, класу, дати уроку, типу матеріалу, дедлайну;
- три **заплановані режими** роботи (чернетка / зараз / за розкладом), але **без відправки в Google**;
- шаблони, URL-матеріали, попередній перегляд;
- копіювання тексту для журналу «Мрія»;
- локальне збереження через IndexedDB;
- експорт та імпорт резервної копії JSON.

## Запуск
1. Розпакувати архів і відкрити `index.html` у сучасному браузері. Для більш передбачуваної роботи IndexedDB та функції копіювання краще використовувати HTTPS-адресу GitHub Pages.
2. Або завантажити папки та файл `index.html` у **корінь** нового репозиторію GitHub.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Перейти за адресою `https://<імʼя>.github.io/<репозиторій>/`.

## Безпека та обмеження
- Немає авторизації Google, підключення Classroom API чи автоматичної публікації. Інтеграція — **етап 2**.
- Локальні дані зберігаються у профілі браузера й не синхронізуються між пристроями.
- Періодично експортуйте JSON, особливо перед очищенням браузера.
- Не додавайте персональні дані учнів, секрети OAuth, паролі чи API-ключі в репозиторій.
- Список класів початково демонстраційний — його можна змінити в «Налаштуваннях».
- Значення дати/часу публікації зберігаються як локальний план, не як фонове нагадування.
